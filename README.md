# BestOJ

一个轻量级 C++ 数学工具库，适用于算法竞赛（OJ）和日常编程。

---

## 📦 功能

| 分类 | 函数 |
|------|------|
| 幂运算 | `power(a, b)` |
| 数论 | `gcd(a, b)`、`lcm(a, b)`、`isPrime(n)` |
| 取模 | `pmod(a, b, mod)` |
| 进制转换 | `tBase(n, base)`、`fBase(n, base)`（2~8进制） |
| 排列组合 | `Permu(n, m)`、`Combi(n, m)`、`fact(n)` |
| 数列 | `fib(n)` |
| 字符串 | `numSum(n)`、`rvsNum(n)`、`isPalind(n)` |

共 14 个函数。

---

## 🚀 快速开始

### 使用静态库

将 `BestOJ.h` 和 `BestOJ.a` 放入项目目录，然后运行。

### 长久使用

将文件放到`include`文件夹

### 快速安装

加载`Fast-install.bat`文件
